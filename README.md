# Supply Chain Dashboard

Interactive analytics dashboard showcasing real-time supply chain metrics and KPIs.

## 🎯 Project Overview

**Jan 2025 – Feb 2025**

An interactive Power BI-style dashboard demonstrating data analysis and visualization capabilities. Processed 150,000+ supply chain records across orders, inventory, suppliers, and shipments.

## 📊 Key Metrics & Features

### KPIs Tracked (20+)
- **Fill Rate**: 94.2% (2.1% above target)
- **On-Time Delivery**: 91.7%
- **Inventory Turnover**: 6.2x
- **Lead Time**: 8.4 days average
- **Order Cycle Time**: 12.8 days
- **Supplier Performance**: 92.1%
- And 14+ more operational metrics

### DAX Measures Implemented (18+)
- Trend calculations (MoM, YoY)
- Rolling averages
- YTD/MTD aggregations
- Variance analysis
- Performance indices

## 🎨 Interactive Features

- **Multi-level Filtering**: Region, Supplier, Product Category, Warehouse
- **Real-time Drill-through**: Click to explore deeper insights
- **Performance Visualizations**: 
  - Regional on-time delivery comparison
  - Category-wise inventory turnover
  - Weekly fill rate trends
  - Supplier performance rankings
  - Warehouse capacity analysis

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Data Processing**: SQL, Power Query, DAX
- **Analysis**: Excel, Power BI
- **Data Volume**: 150,000+ records

## 📁 Data Model

Processing pipeline includes:
- **Orders**: 15,847 transactions
- **Inventory**: 89,000+ SKUs across 3 warehouses
- **Suppliers**: 5 major suppliers tracked
- **Shipments**: Regional and cross-border movement

## 💡 Key Insights Demonstrated

1. **North America leads** with 93.2% on-time delivery
2. **Electronics category** has highest turnover (7.2x)
3. **Supplier A** maintains 98.5/100 quality score
4. **WH-01 (North)** optimizes capacity at 78% utilization
5. **Lead time improvement** of 0.6 days month-over-month

## 🚀 How to Use

1. Open `index.html` in any modern browser
2. Use filter dropdowns to segment data by:
   - Geographic region
   - Supplier performance
   - Product category
   - Warehouse location
3. View real-time KPI updates and trend charts
4. Drill into detailed performance tables
